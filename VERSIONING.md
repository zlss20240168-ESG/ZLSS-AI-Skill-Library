# ZLSS MOU Skill Versioning

## Version Meaning
- v1.x: refinement based primarily on existing validated MOU cases
- v2.0: requires materially broader validation across multiple different MOU types

## Current
Core Skill: v1.0
Execution System: v1.1

## Promotion Standard
A new core rule should normally satisfy at least one:
1. validated in more than one independent MOU case; or
2. validated by a material real-world negotiation outcome; or
3. corrects a high-severity failure that should never recur.

## Case Numbering
CASE-001, CASE-002, ...

## Decision Numbering
Each case uses D-001, D-002, ...

## Principle
Version numbers represent increased decision quality, not increased document length.
