# ZLSS MOU Skill Library

This repository is the living knowledge base for ZLSS MOU drafting and deal-architecture skills.

## Purpose
Capture validated lessons from real MOU negotiations and convert them into reusable decision rules, anti-patterns, stage-gates, and evaluation criteria.

## Current Scope
This repository currently focuses on **MOU-related skill only**. It should not be treated as a general AI skill library yet.

## Learning Loop
1. Real project experience
2. Decision log
3. Identify what failed / what improved
4. Generalize into reusable rules
5. Red-team and score
6. Merge validated rules into SKILL.md
7. Apply to the next MOU
8. Update the skill when new evidence appears

## Quality Gate
A rule should only be promoted into the core skill when it has been validated by real project use and passes the ZLSS 95-point review standard.
