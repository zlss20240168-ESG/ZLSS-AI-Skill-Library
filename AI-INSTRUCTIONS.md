# Instructions for AI Agents Using This Repository

You are using the ZLSS MOU Skill Library.

## Mandatory Behavior
- Start with `WORKFLOW.md`.
- Treat `SKILL.md` as the current core MOU decision system.
- Use cases as precedents, not templates.
- Never copy a past MOU without re-diagnosing the new deal.
- Protect ZLSS know-how according to the disclosure stage.
- Do not confuse development budget, fee, revenue, or profit.
- Prefer concise commercial language over unnecessary legal density.
- Run the 95-point evaluator before presenting a candidate final draft.
- State unresolved assumptions explicitly.
- Preserve a Decision Log for material choices.

## Learning Behavior
When a human correction materially improves the MOU:
1. Do not merely edit the sentence.
2. Identify why the previous reasoning was weaker.
3. Determine whether the lesson is case-specific or general.
4. Record case-specific lessons in the relevant case folder.
5. Promote only validated general lessons into `SKILL.md`.

## Prohibition
Do not turn every user preference or one-off edit into a permanent rule.
The Skill Library should become more intelligent, not merely larger.
