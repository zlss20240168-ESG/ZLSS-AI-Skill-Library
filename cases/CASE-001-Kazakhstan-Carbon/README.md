# CASE-001 — Kazakhstan 500,000 ha Agricultural Carbon Project

## Case Purpose
Capture the validated learning from the evolution of the Kazakhstan agricultural carbon MOU from V1.0 to V2.0.

## Central Learning
The major improvement did not come from adding more legal language.
It came from correcting the transaction architecture and commercial explanation.

## Key Shift
From:
"ZLSS provides services and Party A pays a large amount"

To:
"Party A contributes land, local resources, and development funding; ZLSS contributes carbon-development know-how, international resources, methodology capability, MRV, registration/verification capability, and market access; both sides jointly create new carbon-asset value."

## Why This Matters
The same underlying project can be perceived very differently depending on whether it is framed as:
- a consulting purchase
or
- joint asset development

This case established the first core rule of the ZLSS MOU Skill Library:
**Define the economic architecture before drafting the MOU.**
