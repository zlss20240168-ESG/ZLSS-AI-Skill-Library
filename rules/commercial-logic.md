# Commercial Logic Rules

## Rule CL-001 — Translate Big Numbers Into Natural Units
Large project totals should be supported by a natural unit when possible.

## Rule CL-002 — Show Value Creation
Whenever possible, explain:
Input → Capability Created → Revenue Opportunity

## Rule CL-003 — Separate Revenue From Profit
Never present gross project sales revenue as net profit or as a party's take.

## Rule CL-004 — Use Conservative Planning Assumptions
A credible conservative assumption is often more persuasive than an aggressive promise.

## Rule CL-005 — Explain Why the Counterparty Should Care
The MOU should answer:
- What remains unchanged?
- What new value is created?
- Why does acting now make sense?
