# Deal Architecture Rules

## Rule DA-001
Always identify the economic relationship before drafting language.

Question:
What is each party actually contributing, and what new value is being created?

## Rule DA-002
Do not assume that money paid by Party A is automatically a service fee.

It may instead be:
- development budget
- project investment
- reimbursable project funding
- shared project cost
- asset-development funding

The commercial meaning must be explicit.

## Rule DA-003
If both sides contribute different strategic resources, test whether the transaction is better described as joint development rather than vendor-client service.

## Rule DA-004
The deal architecture controls the MOU tone.
A joint-development MOU should not read like a procurement contract.
